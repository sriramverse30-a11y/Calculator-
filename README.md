# 🧮 Simple Calculator in C

## 📌 About the Project
This is a simple calculator program written in the C programming language. It performs basic arithmetic operations using a `switch` statement.

## ✨ Features
- Addition (`+`)
- Subtraction (`-`)
- Multiplication (`*`)
- Division (`/`)
- Invalid operator detection

## 🛠️ Technologies Used
- **Programming Language:** C
- **Compiler:** Turbo C++

## ▶️ How to Run
1. Open the program in Turbo C++.
2. Compile the code.
3. Run the program.
4. Enter the first number.
5. Enter an arithmetic operator (`+`, `-`, `*`, `/`).
6. Enter the second number.
7. View the result.

## 💻 Example Output

```text
Enter a: 10
Enter operator: +
Enter b: 5
15
```

## 📚 Concepts Used
- Variables and data types
- `printf()` and `scanf()`
- `switch` statement
- Arithmetic operators
- `break` statement
